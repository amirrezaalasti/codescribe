# Next.js App Router checklist

- [ ] Server Components used by default
- [ ] `"use client"` limited to interactive leaves
- [ ] No non-serializable server→client props
- [ ] Layouts vs pages responsibilities are clear
- [ ] `loading.tsx` / `error.tsx` where async routes need them
- [ ] Metadata set for user-facing pages
- [ ] Conventions match the installed Next major
