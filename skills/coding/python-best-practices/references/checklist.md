# Python checklist

- [ ] Public functions have type hints
- [ ] No mutable default arguments
- [ ] Exceptions are specific and handled at boundaries
- [ ] Files/paths use `pathlib` and context managers
- [ ] New code matches existing package/tooling layout
- [ ] Tests exist for non-trivial logic (pytest)
- [ ] No unused imports / obvious dead code
- [ ] Docstrings only where behavior is non-obvious
