# Full review checklist

## Intent
- [ ] Change purpose is clear
- [ ] Scope is appropriate for the PR

## Correctness
- [ ] Happy path works
- [ ] Error paths defined
- [ ] Edge cases listed or handled
- [ ] Backward compatibility considered

## Security & privacy
- [ ] AuthN/AuthZ
- [ ] Injection / XSS / SSRF where applicable
- [ ] Secrets and PII handling

## Tests & observability
- [ ] Tests added/updated
- [ ] Logging/metrics not spammy or leaky

## DX
- [ ] Readable diff
- [ ] Docs updated if needed
