# LaTeX checklist

- [ ] Compiles with the project’s main tex entry
- [ ] Labels/refs for sections, figs, tables, equations as needed
- [ ] Every float is referenced in the running text, and its environment sits after that first reference in the source
- [ ] Figure-internal wording matches the prose, or the mismatch is reconciled in the caption
- [ ] Captions present and informative; the running text interprets each figure rather than only pointing at it
- [ ] Every display equation is referenced later or defines notation used later
- [ ] Bib entries verified; no invented citations
- [ ] Template/class options respected
- [ ] No unnecessary layout hacks
- [ ] AI-slop phrases removed
